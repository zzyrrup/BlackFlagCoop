## Verdict

- **Confirmed:** vt `+0x90` `(0,0)` thiscall returns a pointer that callers treat as an object (field `+0x88`, tag bit).
- **Not confirmed:** that this is `RowSelector::Duplicate`, or that the return (or `+0x88`) feeds `BuildEntityWithSelector`.
- **Falsified for this pass:** unbroken return→Build `r8` chain under current Build heuristic.

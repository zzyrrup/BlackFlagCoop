## Discovered

### Confirmed — modes 2/3 do **not** drive enrollment gate

| Item | Value |
|------|-------|
| Mode stores | `[block+0x158]=2/3` and `dword [r8]=2/3` |
| Mode callees | **`0xB27210`**, **`0x7250E0`/`0x725000`/`0x724EE0`**, plus epilogue helpers |
| Wrap → enqueue/wrapper/worker/gate/membership | **None** |
| BFS depth≤3 enroll hits | **0** |
| Wrap touches `+0x61` | **False** |

**Disambiguation (confirmed):** enrollment eligibility `([obj+0x61]&6)==2` is an **object flag-bit** test. Arm-wrap modes **2/3** are a **separate** side-block/`[r8]` mode enum written into list-helper args. They share the numeral “2” only coincidentally.

Modes 2/3 stay in the membership-family **SmallArray / list** helpers on the `+0x98` side-block — they do not set the enrollment gate.

### Confirmed — `AnimatedOnActiveChanged` same-owner xref

| Item | Value |
|------|-------|
| String RVA | **`0xA179A9F`** (`.edata`) |
| Abs distance to `0x479E440` | **`0x59DB65F`** — **not** nearby (v0.6.18 nearby-string was a false lead) |
| LEA owner | **`0x2335040`** @ `0x2335122` → `lea r9, AnimatedOnActiveChanged` → **`call 0x8CD620`** |
| Post-2B8 E8 caller | Same func: **`call 0x479E440`** @ `0x23350F1` |

**Confirmed:** `0x2335040` both (a) E8-calls post-`+0x2B8` continuation and (b) LEAs `AnimatedOnActiveChanged` for a notify helper. Sibling branch also **`mov [obj+0x26],1`** — ties to the post-2B8 mode gate on `[+0x26]`.

**Hypothesis (not verified):** `0x8CD620` is an event/notify dispatcher keyed by the animation-active string.

Neighbor at **`0x2335140`**: `test edx,~2` then `mov edx,3; call [vt+0x2B0]` — another edx-mode arming-style path (note for later).

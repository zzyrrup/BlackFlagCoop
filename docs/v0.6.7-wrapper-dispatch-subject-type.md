## Discovered

### Confirmed — dispatch path for `0x2E97FC0`

| Step | RVA | Role |
|------|-----|------|
| Phase registrar | `0x5CBDFB0` | Wires named phases to handler/callback bundles |
| Phase name | **`UpdateActorLOD`** | `lea` name at `0x5CBE01F` |
| Callback slot | `[coord+0xE18]` | Stores **`0x1A5A70`** (`0x5CBE045` → `0x5CBE074`) |
| Stub | `0x1A5A70` | `add rcx, 0x10` ; **`jmp 0x2E97FC0`** (`E9` at `0x1A5A74`) |
| Wrapper | `0x2E97FC0` | Enqueues subjects via `0x2E97B60` (v0.6.6) |

Same registration block also stores:

| Coord field | Value | Note |
|-------------|-------|------|
| `+0xE10` | self/`rbx` | bundle header |
| `+0xE18` | `0x1A5A70` | **LOD → enqueue wrapper stub** |
| `+0xE20` | `0` | null |
| `+0xE28` | `0x67BDB30` | sibling helper (`mov rcx,[rcx+8]; mov rdx,[rdx+8]; …`) |
| `+0xE30` | `0x1A5A00` | `mov rax,rcx; mov rcx,rdx; jmp [rax+8]` |

**Control check:** `CreateActorsDeferredSingleThreaded` still maps to drain handler `0x1AC380` (LEA `0x5CBE0DE`). Producer (`UpdateActorLOD` → wrapper) and consumer (`CreateActorsDeferred…` → `0x1AC380`) are **sibling registered phases**.

**Coordinator object model link:** stub adds `+0x10` before entering the wrapper. Wrapper gates on `[rcx+0x180]` ⇒ original `[base+0x190]`, matching the deferred handler’s `[rcx+0x190]` early gate (v0.6.4/5).

### Confirmed — subject type leads (still unnamed)

No MSVC RTTI name was recovered from IP-relative LEAs in `0xE95E80`, `0x725400`, or `0x2E97FC0`.

**Field fingerprint** (object passed as enqueue `rdx` / worker `rcx`):

| Offset | Use |
|--------|-----|
| `+0x00` | Vtable (virtual calls) |
| `+0x18` | Nested ptr → `+0xA8` → `+0x3CD0` (lookup context) |
| `+0x61` | Flag byte; bit2 set on enqueue, cleared by `0x725400` |
| `+0x98` | Receives 0x160 side block from `0xE95E80` |

`+0x18`, `+0x20`, `+0x40`, `+0x48`, `+0x50`, `+0x68`, `+0x88`, `+0x230`.

**Lookup key** for `0x429F9E0`: opaque 16+ bytes at `0xB2898C8` (not ASCII; not an RTTI name).

**Hypothesis (not confirmed):** subjects are LOD-tracked actor-like objects (phase name + distance-like score@slot+8 from v0.6.5). **Not** proven as Edward/player.

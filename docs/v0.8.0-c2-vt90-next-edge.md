## Exact next xref for Agent 2

Disassemble **only** the function stored at vtable slot `+0x90` of the object loaded at `0x1F75E9F` (`mov rax, [rcx]` immediately before the virtual call).

Object path into that `rcx`, from the same window:

```text
incoming this
  -> [this+8]
    -> [that+0x20]
      -> byte [that+0xB] bit 0x80 must be set
        -> [that+0] is the virtual-call this
```

Prove-or-falsify on that slot body:

- **Falsify** both sites if the body does not allocate or copy an object and return the new pointer (a name, query, or getter closes this edge).
- **Keep** the edge only if the body returns a new object. The following xref, and not a new Begin sweep, is then: a caller of this same slot whose saved `rax` is passed as `r8` to a three-argument call `rcx=builder, rdx=lea stack, r8=saved`, with no `r9`.

Do not follow `0xBF3100`, `0xBF2EF0`, or `0x44B210` as the factory. Do not reopen the falsified TLS Begin/Dup leaves unless that slot body reads them.

## Objective 1 — Attribute type dictionary (**verified**)

In `.edata`, a typed field dictionary declares attributes as:

```json
{"name":"<Field>","type":"<primitive>","isOptional":true|false}
```

| Attribute | Primitive type | Optional | Dictionary offset | Evidence |
|-----------|----------------|----------|-------------------|----------|

## Final assessment

1. **Primitive types of PlayerPosX/Y/Z?** **float** (verified dictionary).  
2. **Actually populated by gameplay systems?** **Unknown** — schemas imply gameplay telemetry, but producer/population not proven.  
3. **World-space coordinates?** **Not proven.**  
4. **Telemetry producer identified?** **No.**  
5. **Legitimate local data sink?** **None confirmed** in this offline pass.  
6. **Associate telemetry with Edward’s entity?** **Not verified** (`Character` string only).  
7. **Safest next step toward reading Edward’s position?**  
   - Continue offline: hunt producer symbols / StringId bindings for `player.position` without memory guessing.  
   - Only later, with explicit consent: inspect whether a **local** Ubisoft/diagnostic sink ever materializes these events — read-only, no upload, no ASI offset invention.  
8. **Credible path to two independently controlled Edwards?** **Not from this discovery alone.** Knowing float XYZ telemetry fields does not create a spawn/control pathway for a second Edward.

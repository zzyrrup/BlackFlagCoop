## What “done” means here

A remote Edward can look like the peer only after three separate proofs exist:

1. A Resynced callsite that sets an action target from an alias, a controller channel, and a layer.
2. A Resynced callsite that writes the full primary ground-blend array and a positive time scale, with persistence, on the local player's Human tick.
3. A single action writer. The behavior FSM and the replication path must not both write.

None of those callsites are in the published Resynced evidence. This lane implements the offline snapshot, validation, and apply planner that sit in front of that gap. It does not play an animation.

## Candidate snapshot fields

Version 1 prefix is 64 bytes, little-endian, magic `BFA1` (`0x31414642`), then `blendCount` floats. Unknown flag bits, a bad version, trailing bytes, and a short buffer fail the decode. The codec does not clamp a bad count into range; it rejects it.

| Field | Role | Apply use |
|-------|------|-----------|
| `alias`, `channel`, `layer` | Target triple | `SetTargetAction` on change. `channel` must equal the policy controller channel (default 0) |
| `bodyPartChannel` | Upstream aim/body channel | Stored. Never passed as the blend channel |
| `blendCount`, `blend[]` | Primary ground blender | `PersistAndWriteBlends` only when count equals the configured width |
| `timeScale` | Playback rate | `WriteTimeScale` when finite and in `(0, 64]` |
| `phaseRatio` | Optional seek | `SeekPhase` only on a retarget edge |
| `blendIn*` | Optional transition fix | `PatchBlendIn` only on a retarget edge |
| `characterActionSetId` | Opaque set id | One `ActivateCharacterActionSetOnce` until memory reset |
| `tick` | Stale-packet filter | Refused when `enforceStaleTick` and `tick < minAcceptedTick` |

Ownership: the snapshot is a mod-owned copy. Nothing in it is a pointer. Lifetime is one tick for the bytes, and puppet-generation for `PuppetActionMemory` (CAS-once and last target). Despawn must call `Reset()` so the next puppet re-activates the set. This lane does not implement despawn; the lifecycle lane owns that transition and should call `Reset()` when it clears a puppet.

2. The player-once Human tick is not identified. `AnimatedOnActiveChanged` does not fill that role.
3. This VM has no `ACBlackFlag.exe`, so the next xref pass has to happen where the executable already used by v0.6.19–v0.6.26 is available.

5. Swim, behavior-enable, and matrix authority belong to other lanes and are not solved by an action snapshot.

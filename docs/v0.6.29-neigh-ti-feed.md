## Discovered

### Confirmed — Neighbor TypeInfo is PE-static (SpatRegistrar equivalent)

| Field | Value | Notes |
|-------|-------|-------|
| Meta (Neigh VT`[+0x30]`) | `0xAAD2290` | TypeInfo-shaped record |
| `+0x18` keyHash | `0x2996CA50CB0F23F4` | unique PE embed @`0xAAD22A8` |
| `+0x20` size | `0xB0` | heap size |
| `+0x50` ctor | `0x3D522C0` (NeighRel) | PE-static qword (not zero / not runtime-filled) |

**Confirmed:** Neighbor’s equivalent of SpatRegistrar is a **PE-static TypeInfo record** already holding NeighRel at `+0x50`. There is **no** runtime LEA+store of NeighVT0/NeighRel into `.trace` (0 LEA sites).

### Confirmed — SpatA/SpatB TypeInfo records + construct feeds

| Record | Base | `+0x50` ctor field | How filled |
|--------|------|--------------------|------------|
| SpatTi (Spat VT`[+0x30]`) | `0xACE83F8` | `0xACE8448` = SpatA | SpatRegistrar runtime |
| SpatBTi | `0xACE8478` | `0xACE84C8` = SpatB | SpatRegistrar runtime |

| Feed | RVA | Role |
|------|-----|------|
| Spat VT`[+0x20]` | `0x6CF34E0` | `lea SpatTi` → TiHelper `0x43DCB00` → construct / `+0x98` copy |
| Neigh VT`[+0x20]` | `0x3D52400` | `lea NeighMeta` → TiHelper → construct (parallel) |

**Confirmed:** SpatA/SpatB live at TypeInfo `+0x50` of SpatTi/SpatBTi. The primary offline **construct feed** is VT`[+0x20]` → TiHelper (both families). Tight factories remain generic (no static RIP to SpatTi).

## Discovered

### Confirmed — outer ctor has no direct E8 create site

| Probe | Result |
|-------|--------|
| E8 → `0x59D9660` | **0** |
| LEA → `0x59D9660` | **2** (both InstallerA `@0x5F14901`) |
| E8/LEA → InstallerA `0x5F11A40` | **0** |
| QWORD embed InstallerA | **1** at `.edata 0xA240B20` |

**Confirmed:** InstallerA **LEA-registers** outer ctor into TypeInfo field `0xB289918` (with size `0x20F0` at `0xB2898E8`). There is **no** direct `call 0x59D9660` create site. Construction remains the v0.6.22 generic path: `icall [ti+0x50]` when that TypeInfo is supplied.

InstallerA is itself published as a `.edata` table entry (no E8 callers) — registration/init via table, not a normal call graph.

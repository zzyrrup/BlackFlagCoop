## Investigation 2 — Trace `player.position`

Three `.edata` occurrences:

| Offset | RVA | What it is |
|--------|-----|------------|
| `0xA13E3DE` | `0xA13EDDE` | Packed string-table token near UI/position name inventory |
| `0xA1D77E7` | `0xA1D81E7` | Inside composition declaration `PlayerPosition` → `player.position` |
| `0xA1DE107` / event at `0xA1DE0FE` | `0xA1DE9FE` | **Typed telemetry event schema** |

### Confirmed typed telemetry schema

```json
{"name":"player.position","type":"STANDARD","typeAttributes":[],"customAttributes":[
  {"name":"PlayerPosX"},{"name":"PlayerPosY"},{"name":"PlayerPosZ"},
  {"name":"TimeOfDay"},{"name":"FightState"},{"name":"Movement"},
  {"name":"PositionSource"},{"name":"DistanceTraveled"},{"name":"Ttp"},
  {"name":"World"},{"name":"CurrentPlaythroughId"}
]}
```

| Question | Answer |
|----------|--------|
| Declared? | **Yes** — composition + STANDARD telemetry event |
| Publisher/subscriber code found? | **No** verified code xrefs (strings/schemas only) |
| Serialization/telemetry connection? | **Yes, schema-level** — STANDARD event with attributes |
| Save-game storage proven? | **No** (only SaveGame start/stop context signals found) |
| Value types (`float` etc.) declared? | **Not in this object** |
| World vs UI vs spawn? | **Telemetry payload shape**; world-space **not proven**; UI-only unlikely given `Movement`/`FightState`/`DistanceTraveled`/`World` |

Also: **38** telemetry events in `.edata` include `PlayerPosX`+`Y`+`Z` (combat, quests, menus, inventory, `player.position`, etc.). See `v0.5.4-player-position-trace.json`.

## Investigation 4 — Position representation

**Confirmed**

- Explicit attribute names `PlayerPosX`, `PlayerPosY`, `PlayerPosZ` on many telemetry events  
- Additional related attrs: `PositionSource`, `Movement`, `DistanceTraveled`, `FightState`, `World`  
- Encounter generation also names `WorldEncounterSpawnX/Y/ZCoordinate` (separate from player pose)

**Not confirmed**

- Primitive types / units / handedness / world vs local space  
- `Vector3` / `Quaternion` strings exist elsewhere in `.edata` but **no proven link** to `player.position`  
- Character transform component layout  
- Distinction between live world pose vs last-known telemetry sample vs other spaces beyond schema naming hints  

`initialCharacterPosition` remains a **nav/Havok name-table** token (v0.5.3), not this telemetry schema.

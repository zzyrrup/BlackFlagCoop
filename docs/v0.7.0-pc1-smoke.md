## Launch notes

The process was started at 12:30:39 local time from `C:\Games\AC Black Flag Resynced\ACBlackFlag.exe` with `BFC_SESSION_PANEL=1` on that process only. The installed v0.5.1 file had been copied aside and checked (`63B38877…`, 99840 bytes) before the candidate was copied into place. The candidate was checked again after the copy (`EF7EB82D…`, 112640 bytes).

`VERSION.log` also says `extra plugin modloader\modloader.asi: error 126`. That is the loader missing an optional plugin. `BlackFlagCoop.asi` itself is the next line and is `loaded`.

Desktop capture at 12:31:20 and 12:32:23 showed the IDE, not the game image. `PrintWindow` on the game window returned false. The window enumeration is the evidence the game window existed. The framebuffer was not captured, so the world is not confirmed.

Past clean exits in the save journal write `Save { Platform, Options }`. This launch did not. That is another reason not to treat the save-content load as a finished visit to the playable world.

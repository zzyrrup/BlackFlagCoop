## Network plan (Phase 3 carrier)

Preserve existing TCP framing and handshake. When a verified pose source exists:

1. Prefer `kMsgPlayerStateEx` (type 7) for XYZ + yaw/pitch + movement + `flags` bit0 = verified.
2. Keep `kMsgPlayerState` (type 6) for backward compatibility / degraded peers.
3. Continue presence (join/leave) and session IDs from handshake.
4. **Do not** set `kStateExFlagPoseVerified` until `PlayerTelemetry` is evidence-backed.

**None.** No float offsets, no actor pointers, no RTTI paths are certified for 1.0.6.

## Discovered

### Confirmed — enrollment sites (all inside wrapper)

| Site | Object reg | Source | Gate | Post |
|------|------------|--------|------|------|
| `0x2E98AA3` | `RBX` | packed ptr array `[rdi+rbp]` | `([obj+0x61]&6)==2` | `or [rbx+0x61],4` |
| `0x2E9B3D1` | `RBX` | packed ptr array `[r13+r14]` | same | `or [rbx+0x61],4` |
| `0x2E9B481` | `R14` | packed ptr via `rbp` then untag | same | `or [r14+0x61],4` |

### Confirmed — enrollment feed path (not an allocator)

```
hash-bucket (+0x58/+0x60/+0x68 on manager)
  → SmallArray { base*[+0], count*[+8] }; byteLen=(count<<3)&0x1FFF8
  → load tagged object ptr; untag 0xFFFFFFFFFFFF
  → gate ([obj+0x61] & 6) == 2
  → obj+0x18 → +0xA8 → +0x3CD0 ; lookup 0x429F9E0 ; +0x20
  → 0x2E97B60(coord, obj)
  → or [obj+0x61], 4
```

| Probe | Result |
|-------|--------|
| Wrapper calls allocator `0x426EE50` | **false** |
| Near-site callee → allocator (depth≤5) | **0/1** (`0x537C2C0` = SmallArray pointer scan, no alloc) |
| Feeds that reach helper from alloc-peripheral scan | **0** |
| Static lookup key (sites 2 & 3) | **`0xB2898C8`** (non-string TypeInfo/key blob; shared) |
| Site 1 lookup key | register (`r14`), not the static LEA |

**Verdict:** Helper `0x2E97B60` is fed **pre-existing objects** from manager hash→SmallArray walks inside UpdateActorLOD. There is **no allocator on the enrollment call graph**. Constructors that allocate queue subjects (if any) must populate those arrays **before** this phase — not at the enqueue sites.

### Hypothesis (not verified)

- Objects become enrollment-eligible when some earlier path inserts them into the hashed SmallArrays and sets `[obj+0x61]` so that `&6==2`.
- Worker `0x725400` (clears bit / unlinks) may be the symmetric teardown of the same membership — still not proven as the insert path inverse for this exact array.

### Noise note

A broad “allocator + hot displacement” periphery scan listed many unrelated `0x426EE50` callers (shared Anvil alloc). **None** forward-reached the enqueue helper. Treat that list as negative evidence, not subject-ctor candidates.

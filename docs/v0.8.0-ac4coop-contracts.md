## C0 — Main-thread frame affinity

| Field | Spec |
|-------|------|
| Intent | All create / enroll / drive / despawn run once per frame on the engine main thread, only for the local player’s Human tick. |
| Inputs | Frame tick identity for “this Human is the local player”. |
| Outputs | Permission to run C1–C10 this frame. |
| Ordering | Install once at ASI load; every later contract is gated by this. |
| Ownership/lifetime | Process-lifetime hook; no puppet ownership. |
| Thread | Main thread only. **SC** (`phase1.h` L5–7; `OnFrame` L1013–1014; `isPlayerUpdate` L885–896). |
| Invariants | Must not run spawn/drive for every NPC Human update. |
| Failure | Off-thread call → allocator/scheduler corruption (**AD**). |
| Success criteria | Offline: document chosen Resynced tick site with proof it is player-once-per-frame. Online (later): spawn/drive counters increment exactly once per frame. |
| Offline-now | Design host scheduler + request queue (hotkey/net → flag → main tick). Unit-test queue without engine. |
| Blocked on Agent 2 | Verified Resynced player-Human update (or equivalent) RVA/pattern. |

## C2 — Duplication scope

| Field | Spec |
|-------|------|
| Intent | Produce a **fresh selector copy** inside a balanced global duplication scope, because build **consumes** the selector. |
| Inputs | Live selector from C1. |
| Outputs | `dupSelector` owned by build for consumption. |
| Ordering | `ScopeBegin` → `Duplicate` → **always** `ScopeEnd` (even on fault). Then C3. |
| Ownership/lifetime | Scope is process-global; must not nest unbalanced. `dupSelector` handed to build. |
| Thread | Main thread. |
| Invariants | End runs on every path (**SC** `__finally` L298–302; `DuplicationManager.h` L5–9). |
| Failure | Unreadable dup → abort before build; if End skipped → permanent corruption (**SC** comments). |
| Success criteria | Offline: find paired begin/end around selector/entity clone on Resynced. Online (later): N successful duplicates without subsequent clone faults. |
| Offline-now | SEH/RAII “scope guard” unit tests (no engine). |
| Blocked on Agent 2 | Resynced duplication-manager (or equivalent) pair. |

## C5 — Pad / gamer isolation

## C10 — Despawn / world transition / teardown

| Field | Spec |
|-------|------|
| Intent | Stop driving immediately; remove entity if still alive; reset per-puppet state for a clean respawn. |
| Inputs | Live puppet pointer or “already freed” detection. |
| Outputs | World removal requested; mod state cleared. |
| Ordering | Clear puppet pointer / markers **first**, then `RemoveEntity` if world still holds it (**SC** L855–875). On freed-by-world-travel: drop refs only (**SC** L1055–1064). |
| Ownership/lifetime | After clear, no drive. Cooldown before respawn after world change. |
| Thread | Main thread. |
| Invariants | Never ApplyRemoteState after clear. |
| Failure | Drive-after-free; unbalanced pad marker left set. |
| Success criteria | Offline: teardown state machine tests. Online (later): peer leave removes puppet; world travel respawns later without hijack. |
| Upstream cite | `DespawnPuppet` L855–875; OnFrame drop path L1055–1073. |
| Offline-now | Policy tests. |
| Blocked on Agent 2 | RemoveEntity-equivalent. |

## Discovered

### Confirmed — arming wrap `0x2108620` (541 B)

| Item | Value |
|------|-------|
| Role | Arm-table specialization of canonical `+0x2B8` |
| First call | **`0x479E3B0`** (canonical `+0x2B8`) |
| Then | Loads **`[obj+0x98]`**; early-out if null |
| Flag gates | `[+0x25]`, `[+0x22]`, `test [+0x23],4`; side `test [block+0x84],2` |
| Mode field | Writes **`[block+0x158]`** with **0 / 1 / 2 / 3** |
| List helpers | **`0xB27210`**, **`0xC45FB0`**, **`0xC46110`**, **`0x7250E0`/`0x725000`/`0x724EE0`** |
| E8 callers | **0** (vtable-only) |
| Install site | **`.edata 0x9490208`** = arm-table base `0x948FF50 + 0x2B8` |

**Control flow (confirmed):**
```
0x2108620
  call 0x479E3B0
  rdi = [rsi+0x98]
  if rdi==0 → ret
  if ![+0x25] || ![+0x22] → alternate path (mode 0/3)
  if !(+0x23 & 4) || (block+0x84 & 2) → early ret
  else: set [block+0x158]=1; list work; may set modes 2/3 via dword [r8]
```

Modes **2** and **3** are written both as `byte [block+0x158]` and as `dword [r8]` into list-helper args — same SmallArray “Too many elements…” family as enrollment/membership.

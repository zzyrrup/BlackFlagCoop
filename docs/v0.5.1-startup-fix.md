# BlackFlagCoop v0.5.1 — Startup Hang Fix

**Date:** 2026-11-12  
**Target:** Assassin's Creed Black Flag Resynced 1.0.6  
**Plugin:** 0.5.1

## Why v0.5.0 hung

`InitializeASI` called `PlayerProbe::LogProbeResults()` → `ScanMainModuleHints()`.

That path:

1. Read `SizeOfImage` for `ACBlackFlag.exe` (~501,379,072 bytes).
2. Synchronously byte-scanned the **entire mapped main module** for several needles (`Edward`, `Transform`, `GetPosition`, …).
3. Ran on the loader/init path before the game finished starting.

Logs showed repeated starts ending at `=== Player probe (string hints only) ===` with **no** `=== Player probe end ===`. The game appeared not to launch while the ASI was still scanning.

## What changed in 0.5.1

| Area | Change |
|------|--------|
| `InitializeASI` | No full-module / large memory string scans |
| `PlayerProbe` | Policy stub only (`kEnabledDuringPluginInit = false` + deferred notice) |
| Runtime diagnostics | Kept (PID, path, arch, modules, windows) |
| Networking / splash | Preserved from v0.4.0 behavior |
| Offline research | New `BlackFlagCoopExeStringProbe` scans **on-disk** exe, chunked, bounded, with progress/COMPLETE |
| Coordinates | Still unverified; reader still disabled |

## What remains unknown

Edward’s world position, rotation, and movement-state sources for Resynced 1.0.6 are **still unknown**. No verified offsets or structures. String hits from the offline tool (if any) are research hints only.

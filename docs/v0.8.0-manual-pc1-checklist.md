# v0.8.0 manual PC1 check (user only)

This build does **not** spawn a second Edward. The check confirms the gate log and that Player 1's world is unchanged.

The agent did not launch the game and did not copy this ASI into the game directory.

## Before you launch

1. Leave the installed `BlackFlagCoop.asi` on v0.5.1 unless you explicitly want to load this candidate.
   Known-good SHA256: `63B38877DDA7CC7CD9AB2619F94D3941C37F54C95A435EFE47084DC4CF2A50BE`
2. If you install the candidate, copy the installed ASI aside first and check that backup hash. The Release candidate is `build\bin\Release\BlackFlagCoop.asi`, 102,400 bytes, SHA256 `570F0F91A4B2D4A0B37093FF55BBA601BCC3C296603FE99EF4CD780EC38040B8`.
3. Optional: set user environment variable `BFC_SECOND_EDWARD=1`. A new process inherits it. Ubisoft Connect must be restarted if it was already open when you set the variable. Unset, `0`, or any other value leaves the gate off.

## What you should see

1. Launch Assassin's Creed Black Flag Resynced yourself.
2. Open `%LOCALAPPDATA%\BlackFlagCoop\BlackFlagCoop.log`.
3. Confirm `Plugin version 0.8.0-dev`.
4. Gate off: `Second Edward 0.8.0-dev: gate off`.
5. Gate on: `gate on. REFUSED.` and `Actor created: no.`
6. There is no second Edward in the world. Player 1 still controls the original Edward.

## Stop

Do not treat a loaded world as co-op progress. This candidate never calls the spawn-parameter registrars.

Restore v0.5.1 if you swapped the ASI, and check the restored hash against the value above.
